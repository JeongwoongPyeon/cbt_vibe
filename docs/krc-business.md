# 한국농어촌공사 경상: 필수 회계·재무 개념

[문제 40개와 해설](../outputs/krc-business-40/학습자료.md)에서 아래 번호로 연습할 수 있다. **처음이라면 26 → 28 → 32 → 36 → 38번** 순서로 풀어 보자. 자산의 보유 목적, 공헌이익, 실제시간, 기회비용이라는 판단 기준을 먼저 익히기 위한 학습 순서이며 출제빈도 순위는 아니다.

## 무엇을 근거로 바꾸었나

제공 PDF 7쪽(인쇄 6쪽)은 과거 경상 전공을 일반경영 약 25문항, 회계·재무 약 15~16문항으로 회고한다. 기본 개념과 말문제, 옳은 진술 수 판단이 강조된다. PDF 8~9쪽(인쇄 7~8쪽)은 전공 키워드를 나열하지만 지문·보기·정답이나 키워드별 빈도는 제시하지 않는다. 아래 25+15 구성과 사례·수치는 **창작 연습용**이며 2026년 공식 출제비중이 아니다. NCS·인성검사는 이 전공 세트에서 제외했다.

## 문제 지도

| 번호 | 연습 범위 |
|---|---|
| 1~6 | 포디즘, 포터의 산업구조 분석, 페욜의 명령통일과 지휘통일 |
| 7~13 | M&A 방어전략, SWOT, 카르텔·콘체른, 합명·합자회사 |
| 14~20 | 제품믹스, 조사 설계, 매트릭스 조직, 점포형 소매 |
| 21~25 | 광고 도달률·빈도, 관대화, 인사평가 기법 |
| 26~31 | 투자부동산, 손익분기점·목표이익, 책임중심점 |
| 32~40 | 레버리지, 회수기간과 기업가치, 임률차이, 내부대체가격, 전환사채, 차입원가 |

## 회계: 분류와 계산

| 문항 | 판단 기준 | 예시와 함정 |
|---|---|---|
| 26~27 투자부동산 | 형태가 아니라 **왜 보유하는지** 본다. 임대수익·시세차익 목적이면 투자부동산, 자가사용은 유형자산, 통상 판매 목적은 재고자산이다. | 같은 건물이라도 임대용 사옥과 직접 쓰는 본사의 분류는 다르다. ‘아닌 것’의 개수는 각 항목에 먼저 O/X를 적는다. |
| 28~29 손익분기점 | 단위공헌이익 = 단가 − 단위변동비. 손익분기 수량 = 고정비 ÷ 단위공헌이익. 목표이익이 있으면 분자에 더한다. | 단가 8만 원, 변동비 5만 원이면 1대당 3만 원이 고정비 회수에 기여한다. 고정비 900만 원이면 300대. 판매가 8만 원으로 나누지 않는다. |
| 30~31 책임중심점 | 원가중심점은 비용, 수익중심점은 매출, 이익중심점은 매출과 비용, 투자중심점은 이익과 투자자산까지 책임진다. | 매출·비용을 모두 관리해도 설비투자 결정권이 없다면 이익중심점이다. 배부된 비용이 곧 통제가능한 비용이라는 뜻은 아니다. |
| 36 직접노무원가 | 임률차이 = **실제시간** × (실제임률 − 표준임률). 능률차이 = 표준임률 × (실제시간 − 실제생산량의 허용표준시간). | 실제 300시간, 허용 280시간, 실제 시급 22,000원, 표준 20,000원이면 임률차이 60만 원 불리, 능률차이 40만 원 불리. 양수=불리는 이처럼 실제−표준으로 쓸 때의 부호다. |
| 37~38 내부대체가격 | 공급부문 최저가격 = 내부이전 증분원가 + 포기한 외부 공헌이익. 구매부문의 상한은 동일 조건의 외부 조달비용이다. | 외부가격 10,000원, 생산비 6,000원, 외부판매 수수료 1,000원. 여유능력이 있으면 최저 6,000원, 외부판매를 밀어내면 6,000 + 3,000 = 9,000원. |
| 40 차입원가 | 적격자산은 의도한 사용·판매 준비에 상당한 기간이 필요한 자산이다. 그 취득·건설·생산에 직접 관련되고 요건을 충족한 차입원가는 자산 원가에 포함한다. | 시작은 지출·차입원가·준비 활동이 모두 발생할 때다. 준비 활동이 실질적으로 완료되면 종료한다. 이미 사용 가능한 설비를 대출로 샀다는 사실만으로 이자가 자본화되지는 않는다. |

투자부동산과 차입원가의 분류 근거: [IFRS Foundation IAS 40](https://www.ifrs.org/issued-standards/list-of-standards/ias-40-investment-property/), [IAS 23](https://www.ifrs.org/issued-standards/list-of-standards/ias-23-borrowing-costs/).

## 재무관리: 분모와 현금흐름

| 문항 | 핵심 | 예시와 함정 |
|---|---|---|
| 32~33 레버리지 | 영업레버리지도 = 공헌이익 ÷ 영업이익. 우선주 등 조정이 없을 때 재무레버리지도 = 영업이익 ÷ (영업이익 − 이자). | 공헌이익 4,000만 원, 영업이익 1,000만 원이면 DOL 4배. 기준점 부근에서 다른 조건이 같을 때 매출 1% 변화에 영업이익이 약 4% 변한다는 뜻이지 이익률이 4%라는 뜻은 아니다. |
| 34~35 회수기간·기업가치 | 단순 회수기간은 최초 투자액을 누적 **순현금유입**으로 회수하기까지 걸린 시간이다. NPV는 모든 증분현금흐름을 할인해 초기투자액을 뺀다. | 900만 원 투자, 400·300·400만 원 유입이면 2년 후 200만 원이 남는다. 연중 균등 유입일 때 2.5년. 연말에만 유입되면 3년이다. 회수기간이 같아도 NPV는 다를 수 있다. |
| 39 전환사채 | 전환주식 수 = 전환 대상 금액 ÷ 전환가액. 전환가치 = 주식 수 × 현재 주가. | 액면 100만 원 전액을 주당 2만 원에 전환하면 50주. 주가가 24,000원이면 전환가치는 120만 원이다. 주식 수를 구할 때 현재 주가로 나누지 않는다. |
