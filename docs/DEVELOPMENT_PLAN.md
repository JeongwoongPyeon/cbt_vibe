# AI CBT 개발 계획

## 1. 프로젝트 방향

이 프로젝트는 AI를 활용해 CBT 문제를 만들고, 기존 문제 자료를 정리하며, 풀이 기록과 오답노트를 로컬에 저장하는 개인 학습용 웹앱을 목표로 한다.

문제 자료에는 저작권 이슈가 있을 수 있으므로 초기 버전에서는 서버 배포를 전제로 하지 않는다. 앱은 로컬 환경에서 실행하고, 문제 이미지, 변환된 문제집, 풀이 기록, 오답노트는 사용자의 컴퓨터에 저장한다.

## 2. 핵심 원칙

- 로컬 우선: 문제 데이터와 풀이 기록은 외부 서버에 저장하지 않는다.
- API 키 보호: GPT, Gemini API 키는 `.env`에 저장하고 Git에 커밋하지 않는다.
- 저작권 보호: 문제 원본 이미지, 추출 텍스트, 변환된 문제집 파일은 기본적으로 Git 추적 대상에서 제외한다.
- 호환 가능한 문제 포맷: 모든 문제는 사이트 내부 표준 스키마로 변환한다.
- 검증 가능한 AI 출력: AI가 만든 문제와 해설은 사용자가 검토하고 수정할 수 있어야 한다.

## 3. 권장 기술 방향

### 로컬 웹앱 구조

초기 구현은 `Next.js 로컬 웹앱 + SQLite` 형태를 권장한다. 브라우저에서 보는 사이트처럼 사용할 수 있으면서도, API 키와 로컬 DB 접근은 서버 측 코드에 둘 수 있어 구조가 단순하고 안전하다.

- 프론트엔드: Next.js, React, TypeScript
- 로컬 API: Next.js API Route 또는 Server Action
- 로컬 DB: SQLite
- 데이터 검증: Zod 같은 런타임 스키마 검증 도구
- 엑셀 처리: SheetJS 계열 라이브러리
- 이미지/OCR/문제 정리: GPT Vision 또는 Gemini Vision API
- AI 문제 생성/확장/해설: GPT, Gemini 중 선택 가능하도록 provider 구조화

브라우저에서 AI API를 직접 호출하면 API 키가 노출될 수 있다. 따라서 서버 배포를 하지 않더라도, 로컬에서 실행되는 API 계층이 `.env`를 읽고 AI 요청을 대리 수행하는 구조가 안전하다.

IndexedDB는 브라우저만으로 동작하는 장점이 있지만, 이미지/엑셀 처리, AI 호출, 백업 파일 관리까지 고려하면 SQLite 기반 로컬 DB가 초기 구조에 더 적합하다.

## 4. 주요 기능

### 4.1 문제 풀이

- 4지선다형, 5지선다형, 단답형 지원
- 시험 모드와 연습 모드 제공
- 즉시 채점 또는 시험 종료 후 채점 선택
- 문제별 풀이 시간 기록
- 문제 북마크, 메모, 자신감 표시
- 정답/오답/미응답 상태 저장

### 4.2 오답노트

- 틀린 문제 자동 저장
- 반복 오답 횟수, 최근 오답일, 정답 전환 여부 기록
- 사용자가 직접 오답 사유를 태그로 남길 수 있음
- 예: 개념 부족, 계산 실수, 지문 오독, 암기 부족, 시간 부족
- 오답만 다시 풀기
- 일정 기간 뒤 재출제하는 복습 큐 제공

### 4.3 문제 생성

- 카테고리, 난이도, 문제 수, 문제 유형을 입력해 AI가 문제 생성
- 4지선다형, 5지선다형, 단답형 생성
- 정답, 해설, 핵심 개념, 태그 함께 생성
- 생성 결과는 바로 저장하지 않고 미리보기/수정 단계를 거침

### 4.4 사진 기반 기존 문제 정리

- 문제 사진 업로드
- AI가 문제 번호, 지문, 보기, 정답, 해설 후보를 구조화
- 사용자가 추출 결과를 검토하고 수정
- 내부 문제 포맷 또는 엑셀 파일로 저장
- 원본 이미지는 로컬 보관 여부를 사용자가 선택

### 4.5 엑셀 가져오기/내보내기

- AI가 정리한 엑셀 파일을 사이트 문제 포맷으로 변환
- 변환 전 필드 검증과 오류 목록 제공
- 지원 필드 예시:
  - `type`
  - `category`
  - `question`
  - `choice_1`
  - `choice_2`
  - `choice_3`
  - `choice_4`
  - `choice_5`
  - `answer`
  - `explanation`
  - `tags`
  - `difficulty`
- 문제집을 엑셀 또는 JSON으로 내보내기
- 풀이 기록과 오답노트 백업 파일 내보내기

### 4.6 유사 문제 확장

- 방금 푼 문제를 기준으로 같은 카테고리/개념/난이도의 유사 문제 생성
- 오답 문제를 기준으로 약점 보완 문제 생성
- 단순 복제가 아니라 개념은 유지하고 지문, 보기, 숫자, 상황을 변경
- 생성된 문제는 별도 `AI 확장 문제` 출처로 표시

### 4.7 CBT 기본 기능

- 문제집 목록
- 문제집 생성/수정/삭제
- 카테고리 및 태그 관리
- 제한 시간 설정
- 진행률 표시
- 결과 리포트
- 카테고리별 정답률
- 최근 풀이 기록
- 검색과 필터
- 즐겨찾기 문제

## 5. 데이터 모델 초안

### Question

- `id`: 문제 ID
- `type`: `multiple_choice_4`, `multiple_choice_5`, `short_answer`
- `category`: 카테고리
- `tags`: 태그 목록
- `difficulty`: 난이도
- `stem`: 문제 본문
- `choices`: 객관식 보기 목록
- `answer`: 정답
- `acceptableAnswers`: 단답형 허용 정답 목록
- `explanation`: 해설
- `sourceType`: `manual`, `photo_ocr`, `excel_import`, `ai_generated`, `ai_expanded`
- `sourceNote`: 출처 메모
- `createdAt`: 생성일
- `updatedAt`: 수정일

### Attempt

- `id`: 풀이 기록 ID
- `questionId`: 문제 ID
- `selectedAnswer`: 사용자가 입력한 답
- `isCorrect`: 정답 여부
- `elapsedSeconds`: 풀이 시간
- `mode`: `practice`, `exam`, `review`
- `createdAt`: 풀이일

### WrongNote

- `id`: 오답노트 ID
- `questionId`: 문제 ID
- `wrongCount`: 누적 오답 횟수
- `lastWrongAt`: 최근 오답일
- `resolvedAt`: 다시 맞힌 날짜
- `reasonTags`: 오답 원인 태그
- `memo`: 사용자 메모

### QuestionSet

- `id`: 문제집 ID
- `title`: 문제집 제목
- `description`: 설명
- `questionIds`: 포함 문제 ID 목록
- `createdAt`: 생성일
- `updatedAt`: 수정일

## 6. AI 기능 설계

### Provider 추상화

GPT와 Gemini를 바꿔 사용할 수 있도록 공통 인터페이스를 둔다.

- `generateQuestions(input)`
- `normalizeQuestionsFromImage(input)`
- `normalizeQuestionsFromExcelRows(input)`
- `explainAnswer(input)`
- `expandSimilarQuestions(input)`

### AI 출력 검증

AI 응답은 바로 DB에 저장하지 않고 다음 검증을 거친다.

- 문제 유형이 허용된 3가지 중 하나인지 확인
- 객관식 보기 개수가 유형과 맞는지 확인
- 정답이 보기 또는 허용 답안에 포함되는지 확인
- 필수 필드가 비어 있지 않은지 확인
- JSON 파싱 실패 시 재요청 또는 수동 수정 화면으로 이동

## 7. 구현 단계

### Phase 1. 프로젝트 골격

- 프론트엔드/로컬 API 개발 환경 구성
- `.env` 기반 AI provider 설정
- 로컬 DB 연결
- 기본 라우팅과 화면 구조 생성
- 문제 표준 스키마 정의

### Phase 2. 문제 관리와 풀이

- 문제집 CRUD
- 문제 CRUD
- 4지선다형, 5지선다형, 단답형 풀이 UI
- 채점 로직
- 풀이 기록 저장
- 결과 화면

### Phase 3. 오답노트와 통계

- 오답 자동 기록
- 오답노트 목록/필터
- 오답 재풀이
- 카테고리별 정답률
- 최근 풀이 요약

### Phase 4. 엑셀 호환

- 엑셀 템플릿 정의
- 엑셀 가져오기
- 필드 검증
- 문제 미리보기/수정
- 엑셀/JSON 내보내기

### Phase 5. 사진 인식과 AI 정리

- 이미지 업로드
- AI Vision 기반 문제 추출
- 추출 결과 검토 화면
- 내부 문제 포맷 저장
- 원본 이미지 로컬 보관 정책 적용

### Phase 6. AI 문제 생성과 확장

- 카테고리 기반 문제 생성
- 방금 푼 문제 기반 유사 문제 생성
- 오답 기반 보완 문제 생성
- AI 생성 문제 검수/수정 플로우

### Phase 7. 로컬 백업과 품질 개선

- 로컬 DB 백업/복원
- 문제집 가져오기/내보내기
- 데이터 무결성 검사
- 테스트 작성
- 사용성 개선

## 8. 우선순위 제안

가장 먼저 만들 MVP는 다음 범위가 적절하다.

1. 로컬 앱 실행 환경
2. 문제 스키마와 로컬 DB
3. 수동 문제 등록
4. 4지선다형/5지선다형/단답형 풀이
5. 풀이 기록 저장
6. 오답노트 자동 생성
7. 엑셀 가져오기

AI 사진 인식과 유사 문제 확장은 가치가 크지만, 먼저 문제 포맷과 풀이/저장 구조가 안정되어야 한다. 이 기반이 잡히면 AI 기능은 같은 스키마에 결과를 넣는 방식으로 확장할 수 있다.
