# 디자인 시스템 가이드

이 프로젝트의 기본 디자인 언어는 `DESIGN-notion.md`의 Notion 계열 분석을 따른다. 다만 이 앱은 마케팅 사이트가 아니라 반복적으로 사용하는 CBT 풀이/관리 도구이므로, Notion의 따뜻하고 조용한 문서형 감성을 작업용 앱 셸에 맞춰 적용한다.

## 1. 디자인 방향

- 따뜻한 종이색 배경 위에 흰색 작업 표면을 올리는 차분한 생산성 도구 톤
- 구조적 강조색은 파란색 하나만 사용
- 컬러는 CTA, 링크, 선택/활성 상태, 작은 상태 표시 중심으로 제한
- 문제 풀이, 오답노트, 문제 관리 화면은 정보 밀도와 가독성을 우선
- 과한 히어로, 장식 카드, 큰 마케팅형 섹션은 사용하지 않음
- AI 생성/사진 인식 같은 기능도 설명 위주가 아니라 실제 작업 흐름으로 바로 접근

### 색상 사용 규칙

- `primary`는 주요 행동, 링크, 현재 선택 상태에만 사용한다.
- 보라/핑크/오렌지/틸/그린 계열은 큰 구조색으로 쓰지 않고, 태그 점이나 작은 일러스트 포인트로만 사용한다.
- 전체 페이지 배경은 `canvasSoft`, 실제 문제 풀이 패널과 입력 영역은 `surface`를 기본으로 한다.
- 오답/위험 상태가 필요하면 별도 빨강 계열을 추가하되, 전체 구조색처럼 넓게 사용하지 않는다.

## 3. 타이포그래피

기본 폰트는 Inter 계열을 사용한다.

```css
font-family: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

| Token | Size | Weight | Line Height | Use |
|---|---:|---:|---:|---|
| `heading1` | `40px` | `700` | `1.1` | 큰 섹션 제목 |
| `heading2` | `26px` | `700` | `1.23` | 화면/패널 제목 |
| `heading3` | `22px` | `700` | `1.27` | 카드 제목 |
| `title` | `20px` | `600` | `1.4` | 문제집 제목, 리스트 제목 |
| `bodyMd` | `16px` | `400` | `1.5` | 문제 본문, 기본 문장 |
| `bodySm` | `15px` | `400` | `1.33` | 표, 사이드바, 조밀한 정보 |
| `button` | `16px` | `500` | `1.5` | 버튼 |
| `caption` | `14px` | `400` | `1.43` | 풀이 시간, 정답률, 메타 |
| `eyebrow` | `12px` | `600` | `1.33` | 배지, 작은 라벨 |

CBT 앱에서는 긴 문제 지문과 해설이 핵심이므로 본문은 16px/1.5를 기본으로 유지한다. 큰 display 타이포는 마케팅 히어로가 필요할 때만 사용하고, 앱 내부 화면에는 사용하지 않는다.

## 4. 간격과 형태

| Token | Value |
|---|---:|
| `xxs` | `4px` |
| `xs` | `8px` |
| `sm` | `12px` |
| `md` | `16px` |
| `lg` | `24px` |
| `xl` | `28px` |
| `xxl` | `32px` |

| Radius | Value | Use |
|---|---:|---|
| `xs` | `4px` | 입력 필드, 작은 칩 |
| `sm` | `5px` | 메뉴 항목, 리스트 행 |
| `md` | `8px` | 앱 카드, 유틸리티 버튼, 표면 패널 |
| `lg` | `12px` | 빈 상태, 이미지 미리보기, 넓은 안내 패널 |
| `xl` | `16px` | 모달, 큰 미리보기 컨테이너 |
| `full` | `9999px` | 주요 CTA, 배지, 원형 아이콘 버튼 |

앱 내부의 반복 카드와 패널은 기본적으로 8px 반경을 사용한다. 이미지 미리보기나 빈 상태처럼 디자인 시스템의 부드러운 표면감이 필요한 경우에만 12px 이상을 사용한다.

## 5. 앱 셸

초기 앱 화면은 랜딩 페이지가 아니라 실제 작업 화면이어야 한다.

- 좌측 사이드바: 문제집, 풀이, 오답노트, 가져오기, AI 생성
- 상단 바: 현재 화면 제목, 검색, 설정, AI provider 상태
- 본문: 선택한 작업의 리스트/폼/풀이 화면
- 우측 보조 패널: 문제 메타, 오답 메모, AI 해설, 검증 오류

앱 셸은 `canvasSoft` 배경 위에 흰색 패널을 배치하고, 패널 사이에는 큰 그림자보다 hairline과 여백을 사용한다.

## 6. 주요 컴포넌트 규칙

### Button

- 주요 행동: 파란 pill 버튼
- 보조 행동: 흰색 배경, hairline border, 8px 또는 pill 반경
- 아이콘 행동: lucide 아이콘 버튼 사용
- 삭제/초기화처럼 위험한 행동은 기본 화면에 강하게 노출하지 않고 확인 단계 제공

### Input

- 입력 필드는 흰색 배경, 4px 반경, 얇은 border를 사용
- 포커스는 파란 outline 또는 아주 약한 shadow로 표현
- 문제 지문/해설 입력은 넓은 textarea로 제공

### Card And Panel

- 문제 카드, 문제집 카드, 오답노트 행은 흰색 표면과 hairline 중심
- 카드 안에 또 다른 카드를 중첩하지 않음
- 정보가 많은 화면은 카드보다 표, 리스트, split panel을 우선 사용

### Badge And Tag

- 문제 유형, 난이도, 카테고리, 출처 표시에는 작은 pill 배지를 사용
- AI 생성, 사진 인식, 엑셀 가져오기 같은 출처는 색 점 + 텍스트 조합으로 표시
- 색상은 장식 수준으로 제한

### Table And List

- 헤더는 `eyebrow` 스타일 또는 12px/600 라벨
- 행은 15px 본문과 hairline 구분선
- 정답률, 풀이 시간, 오답 횟수처럼 비교가 필요한 정보는 오른쪽 정렬 숫자로 표시

### Modal And Drawer

- 문제 가져오기 검증 결과, AI 생성 미리보기, 오답 메모 편집은 모달 또는 우측 drawer로 처리
- 큰 shadow보다 흰색 표면, hairline, 적절한 여백으로 구분

## 7. CBT 화면별 적용

### 대시보드

- 최근 풀이, 오답 복습 큐, 문제집 목록을 조밀한 리스트로 배치
- 숫자 요약은 작은 metric block으로 제공
- 장식적인 히어로 문구보다 바로 이어서 풀 수 있는 행동을 우선

### 문제 풀이 화면

- 문제 지문은 넓고 읽기 쉬운 본문 영역에 배치
- 선택지는 큰 클릭 영역과 명확한 선택 상태를 제공
- 채점 전에는 색상 사용을 절제하고, 채점 후 정답/오답 상태를 명확히 표시
- 우측 또는 하단에 해설, 메모, 유사 문제 생성 버튼 배치

### 오답노트

- 오답 원인 태그, 누적 오답 횟수, 최근 오답일, 복습 상태를 한눈에 보이게 함
- 오답 상세에서는 사용자의 메모와 AI 해설을 분리된 섹션으로 표시

### 사진/엑셀 가져오기

- 업로드 이후 AI 추출 결과를 표 형태로 보여주고, 오류가 있는 행을 선명하게 표시
- 저장 전에 반드시 미리보기와 수정 단계를 둠
- 원본 이미지 저장 여부를 명확히 선택할 수 있게 함

### AI 문제 생성

- 생성 옵션은 compact form으로 제공
- 결과는 바로 저장하지 않고 검수 리스트로 보여줌
- 문제마다 수정, 삭제, 저장 선택이 가능해야 함

## 8. 구현 체크리스트

- 색상과 간격은 CSS 변수 또는 디자인 토큰 파일로 먼저 정의
- Inter 폰트 적용
- 기본 앱 셸, 버튼, 입력, 배지, 패널 컴포넌트부터 구현
- 문제 풀이 화면은 본문 가독성과 선택지 터치 영역을 우선 검증
- 모바일에서는 사이드바를 drawer로 접고, 선택지는 세로 리스트로 유지
- 화면을 만들 때 매번 `primary`가 과하게 쓰이지 않았는지 확인
- 카드가 중첩되거나 마케팅 페이지처럼 보이면 리스트/표/패널 구조로 조정
