## 28. 가이드북 · 회계·재무 / 손익분기점

장치 1대 판매가격은 8만 원, 단위변동비는 5만 원, 월 고정비는 900만 원이다. 손익분기 판매량은?

1. 180대
2. 112.5대
3. 450대
4. 300대

**정답: 4번**

1대당 공헌이익=8−5=3만 원. 고정비 900만 원을 충당하는 수량은 900÷3=300대다. 이때 영업이익은 0이다.

## 29. 가이드북 · 회계·재무 / 손익분기점

단위당 공헌이익이 4만 원이고 고정비는 800만 원이다. 세전 목표영업이익 400만 원을 내려면 몇 개를 팔아야 하는가?

1. 300개
2. 100개

4. 400개

**정답: 1번**

필요 공헌이익은 고정비와 목표이익의 합인 1,200만 원이다. 1,200÷4=300개. 200개는 이익이 0인 손익분기 수량이다.

## 30. 가이드북 · 회계·재무 / 책임중심점

부문장이 매출·원가뿐 아니라 부문 자산에 얼마를 투자할지 결정한다. 가장 적합한 책임중심점은?

## 32. 가이드북 · 회계·재무 / 레버리지도

매출액 1억 원, 총변동비 6,000만 원, 영업고정비 3,000만 원이다. 현재 매출 수준에서 영업레버리지도(DOL)는?

1. 3배
2. 1.33배
3. 10배
4. 4배

**정답: 4번**

공헌이익=1억−6,000만=4,000만 원. 영업이익=4,000만−3,000만=1,000만 원. DOL=공헌이익÷영업이익=4배다.

## 33. 가이드북 · 회계·재무 / 레버리지도

영업이익 1,200만 원, 이자비용 400만 원이며 우선주 등 다른 조정은 없다. 재무레버리지도(DFL)는?

1. 1.5배
2. 3배
3. 0.67배
4. 2배

**정답: 1번**

DFL=영업이익÷(영업이익−이자)=1,200÷800=1.5배다. 영업고정비가 만드는 DOL과 달리 이 문제는 이자비용의 효과를 묻는다.

## 34. 가이드북 · 회계·재무 / 회수기간법

설비에 900만 원을 지급하고 1년 차 400만 원, 2년 차 300만 원, 3년 차 400만 원의 순현금유입을 얻는다. 연중 균등 유입 시 단순 회수기간은?

1. 1.5년
2. 2.5년
3. 2.25년
4. 3년

**정답: 2번**

2년 말 누적 회수액은 700만 원이다. 미회수액 200만 원은 3년 차 400만 원의 절반이므로 2+200/400=2.5년이다. 회계이익이 아니라 현금흐름을 더한다.

## 35. 가이드북 · 회계·재무 / 기업가치와 투자안

두 독립 투자안의 단순 회수기간은 같다. 회수 이후 현금흐름이 크게 다를 때 기업가치 증가분을 평가하는 데 가장 직접적인 기준은?

1. 첫해 매출액
2. 단위당 판매량
3. 순현재가치(NPV)
4. 회수기간만의 순위

**정답: 3번**

NPV는 전체 증분현금흐름의 현재가치에서 투자액을 뺀 값이다. 단순 회수기간법은 회수 후 현금흐름과 화폐의 시간가치를 반영하지 못한다.

## 36. 가이드북 · 회계·재무 / 직접노무원가 임률차이

표준임률은 시간당 2만 원, 실제임률은 2.2만 원이다. 실제작업시간 300시간, 실제생산량에 허용된 표준시간 280시간일 때 임률차이는?

1. 56만 원 불리
2. 40만 원 불리
3. 60만 원 유리
4. 60만 원 불리

**정답: 4번**

임률차이는 실제시간×(실제임률−표준임률)=300×0.2만=60만 원 불리다. 허용표준시간 280은 임률차이가 아니라 능률차이를 구할 때 쓴다.

## 37. 가이드북 · 회계·재무 / 내부대체가격

공급부문에 유휴능력이 있다. 내부 주문 1개로 증가하는 원가는 7천 원이며 외부판매를 포기하지 않는다. 공급부문 최소대체가격은?

1. 7천 원
2. 0원
3. 외부판매가 전액
4. 배부고정비 전액

**정답: 1번**

최소대체가격=증분원가+포기한 공헌이익. 유휴능력으로 외부판매를 대체하지 않으므로 기회비용은 0원이며 증분원가 7천 원만 필요하다.

## 38. 가이드북 · 회계·재무 / 내부대체가격

생산능력이 가득 찼다. 외부판매가 1만 원, 단위생산변동비 6천 원, 외부판매에만 드는 수수료 1천 원이다. 내부 이전 1개가 외부판매 1개를 대체할 때 최소대체가격은?

1. 3천 원
2. 9천 원
3. 6천 원
4. 1만 원

**정답: 2번**

포기한 외부 공헌이익=10,000−6,000−1,000=3,000원. 내부 증분원가 6,000원을 더하면 9,000원이다. 내부거래에는 외부 수수료가 들지 않는다.

## 39. 가이드북 · 회계·재무 / 전환사채

액면 100만 원의 전환사채 1매를 전액 주식으로 전환한다. 전환가액은 주당 2만 원, 주가는 2만 4천 원이다. 전환으로 받는 주식의 시가는?

3. 120만 원
4. 100만 원

**정답: 3번**

전환주식수=100만÷2만=50주. 전환가치=50×24,000=120만 원이다. 이는 전환 시 주식의 가치로, 사채의 발행가나 장부금액과는 다르다.
